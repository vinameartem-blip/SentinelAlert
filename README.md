# 🛰️ SentinelAlert — Космический мониторинг состояния угодий

Полноценное браузерное веб-приложение на Python (Streamlit) для высокоточного космического мониторинга сельскохозяйственных угодий по данным европейских спутников **Sentinel-2 L2A**.

---

## 🌟 Основные возможности

- **Прямой запрос к STAC API Microsoft Planetary Computer в реальном времени**: каждый анализ запрашивает метаданные спутников без использования статичных подложек или кэшированных мозаик прошлых лет.
- **Динамический 14-дневный диапазон**: автоматический отбор кадров в окне `[текущая дата минус 14 дней, текущий день]` с фильтром по минимальной облачности.
- **Двухканальная визуализация**: реальный оптический снимок высокого разрешения (RGB True Color) со спутника параллельно с тепловой картой здоровья.
- **Динамический спутниковый тайловый слой**: интеграция WebMercatorQuad тайлов актуального пролета Sentinel-2 прямо в карту Folium.
- **Оконная загрузка Cloud-Optimized GeoTIFF (COG)**: чтение исключительно зоны интереса через `rasterio.windows.from_bounds`, без скачивания гигабайтных сцен.
- **Атмосферная и почвенная коррекция**:
  - **MSAVI2** (Modified Soil Adjusted Vegetation Index) — снижает влияние голой почвы на ранних фазах или разреженных посевах.
  - **EVI** (Enhanced Vegetation Index) — компенсирует влияние атмосферной дымки и не насыщается при густой биомассе.
  - **Ансамблевый индекс здоровья**: `Health_Index = 0.6 * EVI + 0.4 * MSAVI2`.
- **Интеллектуальная фильтрация помех**: канал SCL (Scene Classification Layer, 20м с субпиксельным ресемплингом) автоматически отсекает облака, тени от облаков, снег и водные поверхности.
- **Интерактивная карта (Folium + Esri World Imagery)**: выбор любого поля на планете кликом мыши или вводом координат.
- **Агрономическая аналитика**:
  - Карточки метрик (средний индекс здоровья, площадь здоровой биомассы, зона риска, критический стресс).
  - Автоматический экспертный вердикт и рекомендации для агронома.
  - Экспорт детализированного агро-отчета в Markdown.

## 🚀 Установка и запуск

### 1. Клонирование и подготовка окружения

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Запуск приложения

```bash
streamlit run app.py
```

После запуска интерфейс будет доступен в браузере по адресу:
`http://localhost:8501`

## 📐 Методология расчетов

1. **MSAVI2**:
   $$\text{MSAVI2} = \frac{2 \cdot \text{NIR} + 1 - \sqrt{(2 \cdot \text{NIR} + 1)^2 - 8(\text{NIR} - \text{Red})}}{2}$$

2. **EVI**:
   $$\text{EVI} = 2.5 \cdot \frac{\text{NIR} - \text{Red}}{\text{NIR} + 6 \cdot \text{Red} - 7.5 \cdot \text{Blue} + 1}$$

3. **Ансамбль здоровья**:
   $$\text{Health Index} = 0.6 \cdot \text{EVI} + 0.4 \cdot \text{MSAVI2}$$

4. **Зонирование**:
   - 🔴 **Критический стресс / деградация**: $\text{Index} < 0.20$
   - 🟡 **Зона риска / дефицит влаги**: $0.20 \le \text{Index} < 0.45$
   - 🟢 **Здоровая биомасса**: $\text{Index} \ge 0.45$
