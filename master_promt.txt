Выполни разработку строго по следующей архитектуре:

### 2. Модуль поиска спутниковых снимков (`core/stac_loader.py`)
Напиши функцию `get_sentinel_item(lat, lon, end_date=None, days_back=14, max_cloud=20)`:
1. Используй `datetime.now().date()` как базовую конечную дату, если `end_date` не передан.
2. Подключайся к STAC API Microsoft Planetary Computer: `"https://planetarycomputer.microsoft.com/api/stac/v1"`.
3. Ищи снимки в коллекции `"sentinel-2-l2a"` по координатам `[lon, lat]` за последние `days_back` дней с фильтром `eo:cloud_cover < max_cloud`.
4. Если за последние 14 дней чистых снимков не найдено, автоматически расширяй поиск до 45 дней назад и увеличивай допуск облачности до 35%, чтобы всегда находить самый свежий доступный кадр.
5. Отсортируй результаты (приоритет — самые свежие снимки с минимальной облачностью), выбери лучший кадр и подпиши его через `planetary_computer.sign(item)`.
6. Верни словарь с метаданными (дата съемки, сколько дней назад сделан снимок, процент облачности, ID сцены) и прямыми URL на 4 канала:
   - `"B02"` (Blue, 10m)
   - `"B04"` (Red, 10m)
   - `"B08"` (NIR, 10m)
   - `"SCL"` (Scene Classification Layer, 20m)

### 3. Модуль высокоточного расчета (`core/ndvi_calc.py`)
Реализуй обработку данных через `rasterio` и `numpy`:
1. Функция `compute_health_index(urls, center_lat, center_lon, box_size_meters=1500)`:
   - Вычисли Bounding Box в градусах (EPSG:4326) вокруг `(center_lat, center_lon)` по `box_size_meters`.
   - ВАЖНО: Снимки Sentinel-2 хранятся в проекции UTM. При открытии каждого канала через `rasterio.open(url)` переводи координаты Bounding Box из `EPSG:4326` в `src.crs` с помощью `rasterio.warp.transform_bounds`, затем создавай `window = rasterio.windows.from_bounds(...)`. Скачивай только это окно (технология COG), а не весь гигабайтный файл!
   - Прочитай окна для `B02`, `B04`, `B08` (разрешение 10 м) и приведи их к `float32`, разделив на `10000.0`.
   - ВАЖНО: Канал `SCL` имеет разрешение 20 м. При чтении окна `SCL` передай параметр `out_shape=b04.shape` и `resampling=rasterio.enums.Resampling.nearest`, чтобы размер матрицы `SCL` пиксель-в-пиксель совпал с матрицами 10-метровых каналов.
   - Сформируй маску качества по `SCL`: валидными считаются только классы `4` (растительность) и `5` (открытая почва). Остальные пиксели (облака, тени, вода, снег) помечай как `np.nan`.
   - Рассчитай индекс MSAVI2 (коррекция влияния голой почвы):
     `msavi2 = (2 * b08 + 1 - np.sqrt(np.maximum(0, (2 * b08 + 1)**2 - 8 * (b08 - b04)))) / 2.0`
   - Рассчитай индекс EVI (коррекция атмосферной дымки и перенасыщения):
     `denom = b08 + 6.0 * b04 - 7.5 * b02 + 1.0`
     `evi = 2.5 * ((b08 - b04) / np.where(np.abs(denom) < 1e-6, 1e-6, denom))`
   - Вычисли итоговый ансамблевый индекс здоровья для валидных пикселей:
     `health_index = 0.6 * evi + 0.4 * msavi2`
   - Ограничь значения через `np.clip(health_index, -1.0, 1.0)` и наложи маску `SCL` (`np.nan` для отбракованных пикселей).

2. Функция `analyze_field_metrics(health_matrix)`:
   - Игнорируя `np.nan`, рассчитай по валидным пикселям (1 пиксель = 10x10 м = 0.01 га):
     * Средний индекс здоровья поля.
     * Долю (%) и площадь в гектарах для 3 зон:
       - Критический стресс / деградация: `Health_Index < 0.20`
       - Зона риска / дефицит влаги: `0.20 <= Health_Index < 0.45`
       - Здоровая биомасса: `Health_Index >= 0.45`
     * Процент отфильтрованных помех (облака/тени/вода).

3. Функция `render_heatmap(health_matrix)`:
   - С помощью `matplotlib` построй наглядную тепловую карту с палитрой `RdYlGn` (`vmin=0.0`, `vmax=0.85`), где `np.nan` отображаются серым/прозрачным цветом.
   - Добавь горизонтальную цветовую шкалу (colorbar) с подписями зон: `<0.20 Стресс`, `0.20-0.45 Риск`, `>0.45 Норма`.
   - Если есть связные зоны стресса (`< 0.25`), обведи их заметным красным контуром через `plt.contour`.
   - Верни готовое изображение в буфере `BytesIO` (PNG) для вывода в Streamlit.

### 4. Веб-интерфейс (`app.py`)
Создай интерфейс на Streamlit (`layout="wide"`, заголовок "🛰️ SentinelAlert — Космический мониторинг угодий"):
1. Плашка в шапке: `"Высокоточный ансамбль EVI + MSAVI2 с фильтрацией облаков и теней SCL (разрешение 10×10 м)"`.
2. Боковая панель (`st.sidebar`):
   - Поля ввода широты и долготы (по умолчанию тестовое сельхозполе, например: `51.5300`, `46.0300`).
   - Выбор даты актуальности (по умолчанию `datetime.now().date()`).
   - Слайдер допустимой облачности (5%–40%, по умолчанию 20%).
   - Слайдер радиуса охвата поля (500–3000 метров, по умолчанию 1500 м).
   - Кнопка `"🚀 Запустить космический анализ"`.
3. Две главные колонки (`col1, col2 = st.columns(2)`):
   - В `col1`: Интерактивная карта `folium` со спутниковой подложкой (`Esri.WorldImagery`). При клике мышкой по карте координаты клика автоматически сохраняются в `st.session_state` и подставляются в расчет.
   - В `col2`: Вывод сгенерированной тепловой карты через `st.image()`, дата реальной космической съемки (`"Снимок от DD.MM.YYYY (X дн. назад), облачность Y%"`) и ID спутникового кадра.
4. Блок аналитики под картами:
   - 4 карточки `st.metric`: Средний индекс здоровья, Здоровая площадь (%), Зона риска (га), Критический стресс (га).
   - Автоматический текстовый вердикт (`st.success`, `st.warning` или `st.error`) с рекомендацией для агронома.
   - Кнопка `"📄 Скачать агро-отчет"` (`st.download_button`), генерирующая текстовый/Markdown отчет со всеми координатами, датой пролета спутника, формулами и площадями зон.
5. Кэшируй загрузку данных через `@st.cache_data(show_spinner=False)` и добавь обработку ошибок через `try/except` с понятными уведомлениями для пользователя.

Запусти весь сервер через localhost, после каждого выполненного шага создавай скриншоты и сохраняй в папку Test, создав ее.
